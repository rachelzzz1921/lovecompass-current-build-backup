# 三套题分析话术与词库复用指南

> 目的：结果页、AI 报告、聊天分析师在生成文案时，**共用同一套人情世故规则与槽位模板**，避免三套题各写一套、风格割裂或裸分数伤害用户。

---

## 1. 为什么需要词库层

| 问题 | 词库层解决方式 |
|---|---|
| 三套维度名称不同（SA1–SA6 / AT–RK / FS–MS） | `suiteHooks` 统一各套 primaryOutput 与 dimensionLabels |
| 低分表述容易伤人 | `sharedScoreBands` 五档描述性语言，禁止词列表 |
| 敏感题（颜值/收入/学历） | `sensitiveFieldPhrases` 单独转化，不进雷达主数字 |
| 套间联动文案重复造轮子 | `crossSuiteTemplates` 槽位 + 示例 |
| AI 洞察三条结构相同 | `insightSlots`（strength / watch / growth / match） |

**源文件**：[`../data/analysis_phrase_library_v1.json`](../data/analysis_phrase_library_v1.json)

## 3. 共用分数展示（五档）

所有结果页、雷达详情、AI 摘要**优先使用描述性语言**，逻辑与各套 JSON 内 `score_display_rules.ranges` 一致：

| 分档 | 对用户说 | 禁止说 |
|---|---|---|
| 0–30 | 还有很大的成长空间 | 差、低、不行 |
| 31–50 | 还在发展阶段 | 低于平均 |
| 51–65 | 表现稳定 | — |
| 66–80 | 重要资产 | — |
| 81–100 | 核心竞争力 | — |

**实现建议**：后端 `core_traits.py` / 前端 `scoreDisplaySummary()` 已服务套一；套二套三评分完成后写入 `result_payload.display_summaries`，AI 只读描述不读裸分。

## 4. 洞察槽位（四条模板）

与套一结果页「AI 洞察」Tab 结构对齐，ROS/MATE 可复用：

| 槽位 | 标题 | 用途 |
|---|---|---|
| `strength` | 你的高光 | 最高维 / 最强模块 |
| `watch` | 可以温柔留意 | 最低维 + 正向包装 |
| `growth` | 下一段关系里 | 可操作建议 |
| `match` | 匹配建议 | 类型/定位/红娘区 |

模板变量见 JSON `insightSlots.*.variables`。

## 6. 各套专属钩子（不共用部分）

### 套一 SELF

- Hero 主结果：**依恋类型**（非红楼人物名）  
- 红楼人格：仅「红楼人格」Tab 揭晓  
- 正向包装：`positiveFramingByAttachment`（词库 JSON 已列）

### 套二 ROS

- 主结果：关系类型 + 阶段 + **共鸣指数**（55 分托底）  
- 双人：感知差值、依恋碰撞、关系处方签  
- 绝不劝分

### 套三 MATE

- 主结果：**六种市场定位** + 四象限点  
- 红娘框架：上限 / 经济适用区 / 下限  
- 敏感字段：颜值、收入、学历走 `sensitiveFieldPhrases`

## 7. 结果页区块顺序（建议统一）

**套一 SELF（V3 三幕叙事，详见 [`套一_SELF结果页设计系统_V3.0.md`](./套一_SELF结果页设计系统_V3.0.md)）**

1. OVERTURE — Hero（依恋类型 + 分数球 + tagline）  
2. ACT I — 三面镜（特质 / 画像 / 你会怎样）  
3. ACT II — 红楼揭晓（仪式 + 人物详解 + 匹配）  
4. ACT III — AI 分析师四卡 + 时光机  
5. CODA — 套间解锁 + 分享卡片 + 找 AI 分析师  

**其他单套结果页（ROS / MATE）**

1. Hero（主指标 + 一句话）  
2. 主图表（雷达 / 坐标 / 曲线）  
3. 核心特质或 AI 洞察三条  
4. 解锁区（ROS / MATE teaser）  
5. 找 AI 分析师 CTA  

**个人信息中心**

1. 完整度环  
2. SELF / ROS / MATE 摘要卡片（主指标各套不同）  
3. 时间线  

详见 JSON `reportSectionOrder`。

## 8. AI Prompt 注入顺序

1. 词库 `tonePrinciples` + `forbiddenOutputs`  
2. 套一：依恋 + 六维描述摘要  
3. 套二（若有）：五层 AT–RK + 关系类型/阶段  
4. 套三（若有）：坐标轴 + 定位 + 红娘三区  
5. 用户本题证据（答题 sub/场景，若已实现）
