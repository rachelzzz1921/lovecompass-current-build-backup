## 1. 产品定位

**核心问题：在择偶市场上，别人眼中的你值多少分？**

不是你觉得自己怎么样，是**别人会怎么筛你**。照镜子，不是自我感觉良好。

| 视角 | 核心逻辑 |
|---|---|
| **女版** | 吸引力 × 情感价值 × 现实自主性 |
| **男版** | 资源 × 稳定性 × 情感供给能力 |

**商业定位**：收费，兑换码解锁。

### 1.1 与其他套的联动

```
套一 SELF  → 你是谁（依恋类型 + 红楼人格）
套二 ROS   → 你们怎么样（关系质量 + 双人报告）
套三 MATE  → 你的牌面（市场定位 + 红娘分析）

三套合并 → 终极 AI 画像，实时更新
```

**联动示例（AI 生成）：**

> 你是林黛玉型（焦虑依恋），但你的市场定位是「被读懂之前的人」——你在关系里高度敏感，需要频繁的情感确认，但市场显示度偏低。能发现你的人本来就少，能坚持到真正读懂你的人更少。你最需要的，是先把气质与存在感做上来，让对的人能更快发现你。

## 3. 敏感题处理原则

三类敏感字段**单独处理**，不走普通题型展示逻辑。

### 3.1 女生颜值 → SLIDER 滑杆自评

题干内附参考基准（5–10 分档说明）。  
**结果页**：不显示原始数字，转化为：

- 外形资产：**高辨识度** / **中等辨识度** / **自然型** / **待提升**

### 3.2 男生财富水平 → SLIDER 六档自评

| 档位 | 含义 |
|---|---|
| A 入门层 | 收入勉强覆盖个人基本开销 |
| B 基础层 | 收入稳定，有一定储蓄能力 |
| C 中等层 | 收入高于本城市平均水平 |
| D 中上层 | 有资产积累（房/车/投资） |
| E 优质层 | 本城市收入前 20% |
| F 顶端层 | 本城市收入前 5% |

**结果页**：不显示档位字母，转化为「你的现实底牌在本城市处于中上水平」等描述。

### 3.3 学历 → CHOICE 直接选择

选项：高中/中专及以下 · 大专 · 本科 · 硕士 · 博士及以上  

**处理方式**：作为修正系数，不单独显示。

- 低学历 + 高收入 → 「实践型资产，学历不是核心变量」
- 高学历 + 低收入 → 「轨道在建，潜力尚未变现」
- 结果页不说「你学历低」，只说「你的发展路径偏实践积累型」

## 6. 计分公式

**男女权重不对称是刻意的**，对应现实择偶市场的真实逻辑。

### 6.1 女版

```
横轴（市场显示度）= FS1 × 0.55 + FS2 × 0.45
纵轴（现实支撑力）= FS3 × 0.60 + (100 - FS5) × 0.40

FS1 = FS1_A×0.40 + FS1_B×0.35 + FS1_C×0.25
FS2 = FS2_A×0.40 + FS2_B×0.30 + FS2_C×0.30
FS3 = FS3_A×0.40 + FS3_B×0.35 + FS3_C×0.25
FS4 = FS4_A×0.40 + FS4_B×0.35 + FS4_C×0.25
FS5 = FS5_A×0.35 + FS5_B×0.40 + FS5_C×0.25
```

### 6.2 男版

```
横轴（市场显示度）= MS3 × 0.50 + MS4 × 0.50
纵轴（现实支撑力）= MS1 × 0.55 + MS2 × 0.30 + (100 - MS5) × 0.15

MS1 = MS1_A×0.45 + MS1_B×0.35 + MS1_C×0.20
MS2 = MS2_A×0.40 + MS2_B×0.35 + MS2_C×0.25
MS3 = MS3_A×0.35 + MS3_B×0.40 + MS3_C×0.25
MS4 = MS4_A×0.35 + MS4_B×0.40 + MS4_C×0.25
MS5 = MS5_A×0.30 + MS5_B×0.45 + MS5_C×0.25
```

## 7. 题型分布与设计原则

| 题型 | 用途 | 设计原则 |
|---|---|---|
| SLIDER | 颜值/收入/程度类 | 连续量表，附参考基准 |
| SCENARIO | 行为倾向，高频场景 | 4 选 1，副标题揭示心理机制 |
| BINARY | 二元对峙 | 左右不分好坏，测方向 |
| CHOICE | 单选多维度 | **选项顺序打乱**，不能看出高低 |
| SCALE | Likert 1–5 | 反向题取补数 |
| CARD | 卡片场景 | 降低阅读负担 |
| MOOD | 情绪面板 8 选 1 | 图标优先，测第一感受 |
| RANK | 优先级排序 | 4 项拖拽，判断价值观权重 |

**选项顺序原则**：所有 CHOICE / SCENARIO 的 ABCD 必须打乱，高分选项在 ABCD 中随机分布。

## 8. 四象限坐标系

以 **50 分**为轴线中点。

```
         高现实支撑力（纵轴）
              │
 ②被读懂      │   ①让人想
  之前的人    │   留下来的人
              │
低显示度──────┼──────高显示度（横轴）
              │
 ⑤还没到      │   ③一眼就
  时候的人   │   懂的人
              │
         低现实支撑力

特殊定位（游离于标准象限）：
④ 需要被正确打开的人  →  横轴中偏高，纵轴中
⑥ 越了解越值钱的人   →  横轴低偏中，纵轴高偏中（女 FS2≥65 / 男 MS3≥65）
```

| 象限 | 条件（约） | 定位 |
|---|---|---|
| Q1 | 横≥60 且 纵≥60 | 让人想留下来的人 |
| Q2 | 横<50 且 纵≥60 | 被读懂之前的人 |
| Q4 | 横≥60 且 纵<50 | 一眼就懂的人 |
| Q3 | 横<50 且 纵<50 | 还没到时候的人 |
| special_1 | 50≤横<60 且 50≤纵<60 | 需要被正确打开的人 |
| special_2 | 横<50 且 纵≥55 且 FS2/MS3≥65 | 越了解越值钱的人 |

## 10. 红娘终局分析框架

**不叫「匹配度」**，做成红娘视角的辅助工具。

结构：

1. 你的定位 + 关键词  
2. 你的市场画像（门面 / 资源或吸引力 / 情感供给 / 风险净值）  
3. **上限匹配** — 能吸引，但需主动创造机会  
4. **经济适用区** — 双方匹配度最高，长期关系概率最大  
5. **下限** — 你会觉得累或对方会觉得无聊的类型  

语气：温和，**不说「你只配 xxx」**。

## 11. 分数展示规则（人情世故版）

**核心原则：永远不输出让人难堪的原始数字。**

| 原始分 | 展示语言 | 绝对不说 |
|---|---|---|
| 0–30 | 这个维度还有很大的成长空间 | 很差 / 偏低 |
| 31–50 | 这个维度还在发展阶段 | 低于平均 |
| 51–65 | 这个维度表现稳定 | 任何负面词 |
| 66–80 | 这个维度是你的重要资产 | — |
| 81–100 | 这个维度是你的核心竞争力 | — |

定位描述正向包装示例：

- 「还没到时候的人」→ 不说「你现在不行」，说「你的最好版本正在路上」  
- 「被读懂之前的人」→ 不说「你表达力差」，说「你的价值需要对的人才能读懂」

## 12. 结果页呈现结构

1. **定位名称卡** — 大标题 + 关键词 + 一句话（可截图分享）  
2. **四象限坐标图** — 横轴「市场显示度」，纵轴「现实支撑力」  
3. **模块雷达图** — FS1–FS5 或 MS1–MS5；敏感字段只显示描述性标签  
4. **红娘终局分析** — 上限 + 经济适用区 + 下限  
5. **AI 洞察三条** — 核心优势 / 提升点（正向）/ 套一联动（若做过套一）  
6. **解锁区** — 完整深度报告 + AI 分析师对话

## 13. 与套一联动的特别设计

套一测「你是谁」，套三测「你在找谁 + 你是什么牌面」。

| 套一 | 套三 | 联动要点 |
|---|---|---|
| 林黛玉（焦虑） | 被读懂之前的人 | 敏感 + 低显示度 → 先提升被发现概率 |
| 妙玉（回避） | 让人想留下来的人 | 高留存、低进入率 → 对方需耐心 |
| 安全型 | 让人想留下来的人 | 稳定底盘 + 高留存 → 最少内耗组合 |

AI 生成时读取：`profiles.portrait_cache` 中的 SELF 摘要 + 本次 MATE `result_payload`。
