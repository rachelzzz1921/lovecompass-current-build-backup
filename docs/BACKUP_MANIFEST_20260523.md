## 三、明确排除的内容

| 排除项 | 原因 |
|---|---|
| `.env`、`.env.*` | 可能包含数据库连接串、API Key 或部署密钥。 |
| `node_modules/` | 可由依赖声明重新安装，体积大且不应入库。 |
| `dist/`、`build/`、`.tanstack/` | 可再生成的构建产物。 |
| `__pycache__/`、`*.pyc` | Python 缓存文件。 |
| 终端原始输出日志 | 可能包含冗余路径和不必要的敏感上下文，已由本清单与工作日志替代。 |

## 四、恢复方式

恢复时先克隆本仓库，然后分别进入 `frontend/` 与 `backend/` 安装依赖。后端需要重新配置本地或部署环境变量，包括数据库连接串、Supabase Key、AI Key 等；这些密钥不会从仓库恢复。
